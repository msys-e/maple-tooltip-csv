📥 スカウターに反映
  1. ブックマークバーを表示する（Chrome / Edge / Firefox とも Ctrl+Shift+B）。
  2. 上の 「📥 スカウターに反映」ボタンをブックマークバーへドラッグ＆ドロップする。
    ※クリックしても反映されません。ドラッグしてブックマークとして登録するのが正しい手順です。
  3. maplescouter.com/ja/input を開き、プリセット1 を選んで一度なにか入力しておく。
  4. ブックマークバーの 「📥 スカウターに反映」をクリック。値が入ってページが自動リロードされます。

値を変えたらもう一度「生成」してドラッグし直してください（ブックマークには生成時点の値が焼き込まれています）。
古い「📥 スカウターに反映」ブックマークは右クリック→削除で消しておくと混乱しません。
ドラッグがうまくいかない場合は「URLをコピー」→ ブックマークを手動で新規作成し、URL欄に貼り付けてください。
