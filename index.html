転生更新チェック

取得した転生値を確率分布と比較します。通常職の非武器のみ対応し、Xenon・Demon Avenger・武器は対象外です。

  • ALL%=10、ATT/MATT=4、副ステ=0.1は公式値ではなく参考換算値です。変更すると基準も再計算します。
  • 平均個数は、現在スコアを厳密に上回るまでの期待消費数です。
  • 確率モデルはKMS公式仕様を基準としており、現在のGMSとの一致は未確認です。
  • 特殊な固定Tier装備は、転生区分で対象外に指定してください。
  • 現在と完全に同じ結果を再抽選する処理は、元ライン構成を復元できないため分布に含めていません。

入力した値を maplescouter.com/ja/input のプリセットへ流し込む 使い捨てブックマークレットを作ります。
空欄の項目は送信されません（向こうで設定済みの職業などはそのまま残ります）。

📥 スカウターに反映
  1. ブックマークバーを表示する（Chrome / Edge / Firefox とも Ctrl+Shift+B）。
  2. 上の 「📥 スカウターに反映」ボタンをブックマークバーへドラッグ＆ドロップする。
    ※クリックしても反映されません。ドラッグしてブックマークとして登録するのが正しい手順です。
  3. maplescouter.com/ja/input を開き、プリセット1 を選んで一度なにか入力しておく。
  4. ブックマークバーの 「📥 スカウターに反映」をクリック。値が入ってページが自動リロードされます。

ドラッグできない（禁止マークが出る）ときは手動登録

ブラウザによっては、セキュリティ上 javascript: のリンクをブックマークバーへドロップさせないことがあります。その場合はこちらで確実に登録できます。

  1. 生成結果の 「URLをコピー」 を押す。
  2. Chrome / Edge: Ctrl+Shift+O でブックマークマネージャを開く → 左で「ブックマーク バー」を選び、右側の空白を右クリック → 「新しいブックマークを追加」。
    Firefox: Ctrl+Shift+O でブックマークライブラリ → 「ブックマークツールバー」を選び、右クリック → 「新しいブックマーク」。
  3. 名前に スカウターに反映、URL欄に Ctrl+V で貼り付けて保存。
  4. ブックマークバーに出たそれを、maplescouter のページでクリック。

値を変えたらもう一度「生成」してください（ブックマークには生成時点の値が焼き込まれています）。
手動登録した場合は、そのブックマークを右クリック→編集して新しいURLに貼り替えるのが早いです。
古い「📥 スカウターに反映」ブックマークは右クリック→削除で消しておくと混乱しません。
