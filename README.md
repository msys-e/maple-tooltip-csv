# Maple Tooltip Scanner

MapleStory の装備ツールチップを OCR して CSV 化するブラウザツール。
サーバ不要の静的サイトで、GitHub Pages にそのまま置ける。

## 使い方

1. ページを開き **画面共有を開始** → ゲームウィンドウを選択
2. ゲーム内で装備アイテムにマウスを乗せる → ツールチップを自動検知して表に追加
3. **CSVダウンロード** で全カラム（内訳含む）のCSVを保存

画面共有の代わりに、ツールチップのスクリーンショットを **Ctrl+V / ドラッグ&ドロップ** でも取り込める。

## 取得項目

| 項目 | 内容 |
|---|---|
| 基本ステータス | STR/DEX/INT/LUK/HP/MP/攻撃力/魔力/防御/ALL%/ボスダメ%/防御無視% |
| 内訳 | 合計 / 素値(白) / スターフォース分(黄) / 転生分(水色) |
| ポテンシャル | 各行テキスト + 等級（ブレット色: 緑=Legendary 黄=Unique 紫=Epic） |
| スターフォース | 星アイコンのカウント |

## 機能

- **リアルタイム追加**: ホバーするたび即座に表へ1行追加（検知音つき）
- **重複排除**: 同じ装備を何度ホバーしても1行
- **セルクリックでコピー**: 数値・内訳をクリップボードへ
- **スナップショット**: その時点の表を名前付きで保存 → いつでも復元
- **JSONエクスポート/インポート**: ファイル経由でバックアップ・PC間移動
- 保存先はすべてブラウザの localStorage（サーバに何も送らない）

## OCR の仕組み

汎用OCRではなく、MapleStory のフォントを学習した自前グリフ辞書方式:

```
ツールチップ検出(紺背景) → 行分割 → 色分類(白/黄/水色/橙/緑/紫)
→ 連結成分でグリフ切り出し → グリフ辞書照合(完全一致→ハミング距離)
→ 正規表現パース → CSV
```

固定フォント・固定スケール前提のため実運用でほぼ100%の精度。
未知の文字が出たらその場でラベル付けでき、辞書はブラウザに保存されて育つ
（`data/glyphbank.json` が同梱の学習済み辞書）。

## 開発

```
python -m http.server 8471   # ローカル確認 (test.html がデバッグページ)
node test/run.mjs seg        # 行/グリフ分割の確認
node test/run.mjs label      # golden整列で辞書を再構築
node test/run.mjs ocr        # OCR全行一致テスト
node test/run.mjs parse      # パース結果のgolden比較
```

`samples/` の3枚 + `test/golden/` が回帰テスト。認識ロジックを触ったら
`npm test` (ocr+parse) が緑のままであることを確認する。

## 制限

- 英語クライアントのツールチップのみ学習済み
- ゲームのUIスケールは等倍前提（ツールチップ幅 ~325px）。幅が想定外のときは
  誤読を避けるため警告してスキップする
- 画面端で欠けたツールチップはスキップ（マウス位置をずらすと反対側に出る）
