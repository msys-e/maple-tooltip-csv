# 強化プランの計算メモ

確認日: 2026-08-02

## キューブセール

強化プランの「キューブセール 25% OFF」を有効にすると、`data/ranking.csv` の潜在能力行について、期待メソとメソ/スコアを通常時の75%として再計算する。グローイングキューブとブライトキューブの両方が対象で、スターフォース行には適用しない。順位は割引後のメソ/スコアで並べ直す。

対象地域はGMS。割引率は、Nexon公式MapleStoryフォーラム内で2024年11月時点の通常のキューブセールを25%引きとしている記述を参考にした。

- 参考: [Future Cube Sales - Official MapleStory Website](https://forums.maplestory.nexon.net/discussion/34969/future-cube-sales)

この記述は公式告知ではなくユーザー投稿であり、今後のセールで割引率、対象キューブ、購入上限が同じとは限らない。実際の開催条件が異なる場合、この固定25%切替では再現できない。

## 表示する強化の種類

強化プランの「表示」は「すべて」「キューブ」「スタフォ」を切り替えられる。既定は従来と同じ「すべて」で、キューブを選ぶと潜在能力行、スタフォを選ぶとスターフォース行だけを表示する。順位、対象装備数、アクション数は絞り込み後の行で付け直す。

この表示切り替えは計算条件を変えず、「全段階を表示」や「キューブセール 25% OFF」と併用できる。種類の選択はページを再読み込みすると「すべて」に戻る。

潜在等級がLegendaryでも潜在能力の本文を1行も取得できていない装備は、0ライン完成品とはみなさない。「全段階を表示」でもキューブ候補から外し、再取り込みが必要な装備として注記する。

表下部の対象外注記も選択中の表示種類を基準にする。たとえば「キューブ」表示では、同じ装備にスタフォ候補があっても、潜在能力の本文未取得という理由を隠さない。「すべて」表示でも片方だけに候補がある場合は、もう片方が対象外である理由を強化種類付きで表示する。

現状と開始条件が一致する効率表行がない装備・強化種類では、到達可能な行のうちメソ/スコアが最も低い1件を通常の優先候補として無印で表示する。「全段階を表示」では残りを「先」として追加する。優先候補の期待メソとスコアは、表示行に記載された開始条件（例: `←2ライン`）を基準とする目安であり、現在値からの厳密な差分ではない。

上記の目安が含まれる場合は表下部へ開始条件基準である旨を表示する。対象候補が0件でも対象外注記は消さず、スタフォのみ表示では「スタフォ不可」「スタフォ数不明」も区別する。
